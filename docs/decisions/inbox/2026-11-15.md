### 587. [pop-progression] raidmimic.com flag tracker opens to anyone: paste or file, 50 characters, matrix first (2026-11-15)

- **The ask (the guild lead):** *"by the end of today I would like to be able to open up raidmimic.com for anyone to
  register and be able to track their progress … drop in either their pop flags file or copy in the lines. obviously we
  need protection in place to drop any bad actor sql, commands, etc and safeguard privacy."* Then, after loading eight
  characters: *"Allow more than 8 characters. Show the Matrix view … Order from most flags to least flags. Allow for manual
  entry of character name and their seer or popflags messages, pruning out any of the unexpected entries. Look for
  alternative ascii characters."*
- **The call:** https://raidmimic.com/characters (already live since §545, anyone with Discord can sign in) takes a pasted
  `#popflags` reply or Seer recital as well as Zeal's file; 50 characters per player (was 8); the flag matrix of the
  player's own characters first, most flags first.
- **Safety:** pasted text is normalised (NFKC, curly quotes, dashes, odd spaces, zero-width and control characters),
  capped at 64 KB / 800 lines before parsing, and matched line by line against the closed catalog; only catalog keys
  are stored, unrecognised lines are counted, never stored or echoed. Writes are parameterised upserts of catalog keys;
  names are letters only. Tables stay service-role only (RLS on, no policies), every read and delete keyed on the
  signed-in player. Durable limit: 20 imports per player per hour (`hub_import_attempts`), failing open on a database
  error with the in-memory limiter as the first layer. Per-character remove button; the privacy page says what is kept.
- **Where:** web 2.1.144, bot 4.0.85 (prune), migration `20261115120000_hub_import_attempts.sql` (applied); STATUS
  2026-11-15.

### 588. [infra-costs] Raid Mimic money: live party merging is free and donation-funded; hosted replays are what we charge for (2026-11-15)

- **The call (the guild lead):** *"same day overlay data merging is done on the new bot, donation based up front. the
  hosted replays are the main point to charge for, the rest we can eat up front and show the cost of it on the site"*.
- **What it means:**
  - The party relay (apps/raidmimic-relay, its own Railway project) merges a group's or raid's live overlay numbers for
    everyone, free, with a way to donate. It keeps 10 minutes in memory and stores nothing.

    product. Recaps (positions per minute, drops, rolls, attendance, per-ability totals, ~40 MB per guild-week) and
    everything else stay free for now; replays otherwise live on each player's own Mimic.
  - The site shows what running it costs (a public running-costs page), so donations have a number to aim at.
- **Supersedes** the relay's Free / Pro-trial caps written the same day (6 members and two streams for free): the
  relay's limits become the same for everyone; the trial and tier plumbing stays in place for hosted replays.
- **Open:** the replay price and how a donation is taken (to pick); Vercel's commercial-use terms if money is taken.
