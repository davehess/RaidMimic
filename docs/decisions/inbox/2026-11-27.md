### 661. [mimic-overlays] A 2x default UI exists (corrects §658); the radar lines up by hand until Zeal sends the camera (2026-11-27)
- **Correction to §658.** It said no 2x skin exists for Quarm. A community 2x upscale of the default UI does exist ("defaultx2",
  the default client UI with every size doubled).
  - The guild lead shared four window files written for it: bank, merchant, loot and inventory.
  - Bank: 30 personal and 10 shared slots.
  - Merchant: Quarm's recharge button, price and charges. A skin without them makes the client complain.
  - Loot: Link All and Loot All.
  - Inventory: shows mana as current / max, and the AA bar in the AA window's colour.
  - The files are not ours to ship and are not in the repo. They are the reference for the 200% step of UI Studio's
    bigger-skin option (Desk `ui-scale` C).
  - Their default spots assume a 4K screen (inventory at x 2978; loot window 1,489 tall). On a smaller screen the UI file's
    saved positions decide, so a player without them gets windows half off-screen. UI Studio's screen fitting (FB-132)
    would cover that.

  issues"*).

    height, tilt and field of view by hand, saved per player.
  - The radar is now solid while blind; Mimic's opacity setting had been fading it.
